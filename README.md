# Календарь задач (Android / Kotlin)

Мобильное Android-приложение для планирования задач по дням с локальным хранением данных на устройстве (без серверной части и внешних API). Разработано в рамках семестрового практического задания по курсу «Мобильная разработка (Android, Kotlin)».

## Функционал

### Основной функционал
- **Календарное представление:** собственная календарная сетка месяца на базе `RecyclerView` + `GridLayoutManager(7)` с переключением месяцев, выделением текущего и выбранного дня и индикаторами (точками) на днях с задачами.
- **Полный CRUD:** создание, просмотр, редактирование, отметка о выполнении (`CheckBox` с зачёркиванием) и удаление задач свайпом с диалогом подтверждения.
- **Форма создания и редактирования:** один переиспользуемый экран (`AddTaskActivity`) с `DatePickerDialog`, `TimePickerDialog`, автоподстановкой выбранного в календаре дня и валидацией ввода.
- **Локальное хранилище:** база данных SQLite через библиотеку Room (`tasks_table`), все операции выполняются асинхронно в корутинах (`Dispatchers.IO`).
- **Локальные уведомления:** точные напоминания по дате и времени через `AlarmManager` и `BroadcastReceiver`, создание `NotificationChannel`, запрос разрешения `POST_NOTIFICATIONS` (Android 13+), автоматическая отмена при удалении/выполнении/переносе задачи.
- **Поиск, сортировка и пустые состояния:** фильтрация в реальном времени через `SearchView` (по названию и категории), сортировка средствами SQL `@Query` (по дате/времени, по алфавиту, сначала невыполненные, по приоритету), информативные пустые состояния.
- **Тёмная тема:** переключение между системной, светлой и тёмной темой с сохранением выбора в `SharedPreferences` и адаптивной палитрой в `res/values` и `res/values-night`.

### Дополнительный функционал
- **Категории и приоритеты:** выбор категории задачи («Личное», «Учёба», «Работа», «Здоровье», «Покупки», «Другое») и уровня приоритета (Низкий / Средний / Высокий) с цветовой индикацией на карточках и отдельной сортировкой.
- **Восстановление напоминаний после перезагрузки:** `BootReceiver` отслеживает `BOOT_COMPLETED` и заново планирует актуальные будильники из базы Room.
- **Экспорт и импорт в JSON:** резервное копирование и восстановление задач через системный проводник Android (Storage Access Framework) с автоматической защитой от дубликатов.
- **Виджет на главный экран:** отображает задачи на текущий день с приоритетами и статусом выполнения, автоматически обновляется при изменении задач и поддерживает быстрое добавление задачи (`+`) и ручное обновление (`↻`).

## Технологический стек и архитектура

- **Язык:** Kotlin
- **Минимальный SDK:** API 26 (Android 8.0+)
- **Архитектура:** MVVM (`Activity` → `TaskViewModel` → `TaskRepository` → `TaskDao` / `Room`)
- **Асинхронность и реактивность:** Kotlin Coroutines (`viewModelScope`, `Dispatchers.IO`), `LiveData`, `MediatorLiveData`
- **Интерфейс:** XML-разметка, Material Design Components, `RecyclerView`, `CardView`, `ItemTouchHelper`
- **Хранение настроек и данных:** Room (SQLite), `SharedPreferences`, `org.json`

## Структура проекта

```text
app/src/main/java/ru/university/calendar/
├── Task.kt                 # Room Entity (таблица tasks_table)
├── TaskDao.kt              # DAO: CRUD, фильтрация по дате, поиск и SQL-сортировка
├── AppDatabase.kt          # Синглтон RoomDatabase (версия 3)
├── TaskRepository.kt       # Слой репозитория между ViewModel и DAO
├── TaskViewModel.kt        # ViewModel, состояние экрана, бэкап с дедупликацией

├── CalendarDay.kt          # Модель ячейки календарной сетки
├── CalendarAdapter.kt      # Адаптер календаря (GridLayoutManager на 7 столбцов)
├── TasksAdapter.kt         # Адаптер карточек задач с приоритетом и CheckBox
├── MainActivity.kt         # Главный экран: поиск, управление, календарь, список задач
├── AddTaskActivity.kt      # Экран создания и редактирования задачи
├── DetailActivity.kt       # Экран подробного просмотра задачи
├── AlarmScheduler.kt       # Планирование и отмена напоминаний через AlarmManager
├── NotificationHelper.kt   # Создание NotificationChannel и показ уведомлений
├── TaskAlarmReceiver.kt    # BroadcastReceiver для показа сработавшего напоминания

├── ThemePreferences.kt     # Сохранение и применение темы через SharedPreferences
├── TaskJsonHelper.kt       # Сериализация и парсинг задач в JSON
└── TaskWidgetProvider.kt   # Виджет на главный экран со списком задач на сегодня
```

## Инструкция по сборке и запуску

1. Клонируйте репозиторий и откройте папку проекта в **Android Studio**.
2. Дождитесь завершения синхронизации Gradle (**Sync Project with Gradle Files**).
3. Подключите физическое устройство или запустите эмулятор с **Android 8.0 (API 26)** или выше.
4. Нажмите **Run (`Shift + F10`)**.
5. При первом запуске на Android 13+ разрешите отправку уведомлений для проверки напоминаний.

## Сценарий проверки основных функций

1. **Календарь и CRUD:** выберите любой день в календаре, нажмите `+`, создайте задачу с категорией, приоритетом и временем через 1–2 минуты. Убедитесь, что под датой появилась точка-индикатор, а после сворачивания приложения пришло уведомление.
2. **Поиск и сортировка:** введите часть названия или категории в строку поиска, переключите режимы сортировки кнопкой «Сортировка».
3. **Тёмная тема:** переключите тему кнопкой «Тема» и перезапустите приложение — выбор сохранится.
4. **Резервная копия:** выполните экспорт через «Бэкап → Экспортировать задачи в JSON», удалите одну задачу и выполните импорт — восстановится только удалённая задача, существующие дубликаты будут пропущены.
5. **Виджет:** добавьте виджет приложения на рабочий стол устройства — отобразятся задачи на сегодня с возможностью быстрого добавления новой задачи.
